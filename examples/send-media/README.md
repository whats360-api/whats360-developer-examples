# Send media

`send-media.sh` wraps the documented endpoints `send-image`, `send-video`, `send-audio` and `send-doc`. Parameters come from the [API reference](https://github.com/whats360-api/whats360-api-docs/blob/main/api-reference.md). "Media upload" as a separate endpoint is not documented; you pass a public URL instead. If you get error 463, see the errors page.
